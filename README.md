# Proyecto de QA Manual

<img src="docs/proconnect.png" alt="ProConnect Logo" style="width: 55%;">

**Proyecto de QA Manual** desarrollado en colaboración por un equipo para la plataforma **ProConnect**, una solución digital de reclutamiento y selección de personal diseñada para conectar empresas con candidatos y facilitar la gestión de ofertas laborales y postulaciones.

## Objetivo

Validar las funcionalidades principales de la plataforma ProConnect, identificando posibles errores y oportunidades de mejora durante el desarrollo y preparación para la presentación del proyecto.

- **Autenticación**: Registro, inicio de sesión y recuperación de contraseña.
- **Gestión de Ofertas**: Creación, edición y eliminación de ofertas laborales.
- **Postulaciones**: Búsqueda, postulación y seguimiento de ofertas.
- **Gestión de Solicitudes**: Actualización del estado de las candidaturas.
- **Notificaciones**: Comunicación de cambios en el estado de las postulaciones.
- **Administración**: Gestión de usuarios y acceso al portal administrativo.

## Alcance del Testing

- **Tipos de prueba**: Funcionales, Exploratorias, Usabilidad y Compatibilidad/Responsive.
- **Casos de prueba**: Se reconstruyeron casos de prueba a partir de la documentación funcional y los requerimientos del sistema.
- **Pruebas exploratorias**: Se realizaron durante el desarrollo y especialmente antes de la presentación, enfocadas en las funcionalidades principales.
- **In Scope**: Registro, inicio de sesión, recuperación de contraseña, gestión de ofertas, postulaciones, solicitudes, notificaciones, administración y gestión de usuarios.

> **Aclaración:** El proyecto fue desarrollado para una **Demo Day**, por lo que el tiempo disponible para realizar las actividades de QA fue limitado. Durante el desarrollo y especialmente antes de la presentación se realizaron pruebas exploratorias sobre las funcionalidades principales.
>
> Los casos de prueba incluidos en este repositorio fueron reconstruidos a partir de la documentación funcional y los requerimientos del proyecto. Debido a las limitaciones de tiempo, estos casos no llegaron a ejecutarse formalmente, por lo que los campos de resultado, estado y evidencias se encuentran pendientes de ejecución.
>
> Esta documentación diferencia los casos de prueba diseñados de las pruebas exploratorias que efectivamente se realizaron durante el desarrollo y la Demo Day.

## Requerimientos Cubiertos

| Requerimiento | Descripción |
|---------------|-------------|
| **RF1** | Registro e inicio de sesión para reclutadores, candidatos y administradores. |
| **RF2** | Restablecimiento de contraseña mediante enlace por correo electrónico. |
| **RF3** | Creación, edición y eliminación de ofertas de empleo. |
| **RF4** | Gestión del estado de las solicitudes: aceptación, rechazo o actualización. |
| **RF5** | Búsqueda, postulación y seguimiento de ofertas de empleo. |
| **RF6** | Sistema de notificaciones sobre actualizaciones de solicitudes. |
| **RF7** | Portal administrativo exclusivo para administradores. |
| **RF8** | Gestión de usuarios, con opciones de creación, edición y eliminación. |
| **RNF1** | Cifrado de contraseñas y protección de datos sensibles. |
| **RNF2** | Accesibilidad desde dispositivos móviles, tabletas y escritorio. |
| **RNF3** | Diseño intuitivo y facilidad de uso. |
